# Preuves de contrôle

`browser-report.json` est produit par `tests/browser.cjs` sur la distribution locale 7.0.0. `unit-tests.txt` conserve la sortie du dernier passage des 35 tests.

Les captures complètes sont régénérées dans `qa-results/` par le test navigateur ; elles ont été inspectées pendant la réception. Ce dossier n’est pas un stockage de données métier.
