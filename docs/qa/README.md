# Preuves de contrôle

`browser-report.json` reprend le dernier rapport produit par `tests/browser.cjs` sur la distribution locale 7.1.0. `unit-tests.txt` conserve le reçu synthétique du dernier passage des tests métier et DOM.

Les captures complètes sont régénérées dans `qa-results/` par le test navigateur ; elles ont été inspectées pendant la réception. Ce dossier n’est pas un stockage de données métier.
