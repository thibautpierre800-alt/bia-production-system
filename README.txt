BIA Production System — prototype Android gratuit
1. Héberger ce dossier sur un site HTTPS (GitHub Pages, Netlify, Cloudflare Pages).
2. Ouvrir l'adresse sur Android avec Chrome.
3. Chrome > menu > Ajouter à l'écran d'accueil / Installer l'application.
4. Le prototype fonctionne localement dans le navigateur.

Le prototype actuel stocke les actions et Gemba dans le téléphone (localStorage).
Il ne synchronise pas encore les 7 sites entre utilisateurs.
